# 🛡️ CyberSeguranca 2.0

🎯 Objetivos do projeto

- Apresentar conceitos fundamentais de cibersegurança.
- Informar sobre ameaças digitais e formas de prevenção.
- Explorar carreiras e oportunidades profissionais na área.
- Oferecer um quiz interativo para testar os conhecimentos dos visitantes.
- Permitir a geração de QR Codes para links e textos personalizados.
- Facilitar o acesso ao projeto por meio de um QR Code.

🚀 Funcionalidades

🏠 Página inicial

- Apresentação do projeto.
- Conteúdo educativo sobre cibersegurança.
- Informações sobre ameaças digitais.
- Conteúdo sobre carreiras na área.
- Navegação para as demais páginas.

🧠 Quiz de cibersegurança

- Questionário com 10 perguntas.
- Cronômetro para responder às perguntas.
- Pontuação baseada nos acertos e na velocidade das respostas.
- Resultado final com a pontuação obtida.
- Opção para reiniciar o quiz.

📱 QR Code

- QR Code para acessar o site.
- Gerador de QR Codes personalizados.
- Possibilidade de gerar códigos a partir de textos ou links.
- Opção para baixar o QR Code gerado.

🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** interações, cronômetro, pontuação e geração de QR Codes.
- **Git e GitHub:** versionamento e hospedagem do código.
- **GitHub Pages:** publicação do site na internet.

▶️ Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Navegue pelo site e teste suas funcionalidades.

Para clonar o repositório, utilize:

```bash
git clone https://github.com/Lightis4/CyberSeguranca2.0.git
```

Em seguida, entre na pasta:

```bash
cd CyberSeguranca2.0
```
